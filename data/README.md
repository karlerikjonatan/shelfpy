# Search-term lists

Put your search-term files here — flat JSON arrays of strings, e.g.:

```json
["Author", "Author"]
```

Keep as many as you like side by side. Point `AUTHORS_PATH` at whichever one a given run should use; it defaults to
`data/authors.json`. None of these files are committed (see `.gitignore`) —
this README is just here so the folder exists after a fresh clone.
